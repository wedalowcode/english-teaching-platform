# 第17篇：角色管理增加权限分配：通过复选框配置角色权限

上一节完成了角色管理和角色成员管理。本节继续完善角色管理，在“更多”操作中增加“分配权限”，实现角色权限的查看、勾选和保存。

本节不新增权限表，也不改变现有权限模型，直接使用已经建立的 `PERMISSIONS` 权限目录和 `RolePermission` 关联表。

## 一、先明确权限分配规则

当前系统有两类权限：

- `SYSTEM`：系统管理权限，例如用户管理、角色管理。只有 `SUPER_ADMIN` 可以通过系统级规则获得，不允许普通角色勾选授权。
- `BUSINESS`：业务权限，例如学生管理、课程管理、排课管理，可以分配给普通角色。

因此，权限配置页面只展示满足以下条件的权限：

```ts
permission.domain === "BUSINESS" &&
permission.grantable
```

还有一个容易忽略的细节：`RolePermission.scope` 是必填字段。

- 不支持数据范围的权限，固定使用 `ALL`。
- 支持数据范围的权限，允许选择 `ALL`、`OWN`、`ASSIGNED`。

最终保存的是权限编码和对应的数据范围，而不只是一个勾选状态。

## 三、增加权限配置查询服务

修改：

`features/roles/service.ts`

增加以下查询方法：

```ts
import { PERMISSIONS } from "@/lib/auth/permissions";

import type {
  PermissionCode,
  PermissionDefinition,
} from "@/lib/auth/permissions";

export async function getRolePermissionConfig(roleId: string) {
  await requirePagePermission("role.assignPermissions");

  const role = await db.role.findUnique({
    where: { id: roleId },
    select: {
      id: true,
      code: true,
      name: true,
      isSystem: true,
    },
  });

  if (!role) return null;

  const permissions = Object.entries(PERMISSIONS)
    .filter(
      ([, item]) =>
        item.domain === "BUSINESS" && item.grantable
    )
    .map(([code, item]) => ({
      code: code as PermissionCode,
      name: item.name,
      module: item.module,
      scopeable: item.scopeable,
    }));

  const assigned = await db.rolePermission.findMany({
    where: {
      roleId,
      permissionCode: {
        in: permissions.map((item) => item.code),
      },
    },
    select: {
      permissionCode: true,
      scope: true,
    },
  });

  return {
    role,
    permissions,
    assigned,
  };
}
```

这里有两个重要设计：

1. 权限名称、模块和是否支持数据范围全部来自 `PERMISSIONS`，不在数据库中重复维护。
2. 查询已有授权时，只读取当前允许分配的权限，避免把系统内部权限展示给普通角色。

## 四、实现权限保存操作

修改：

`features/roles/actions.ts`

先增加保存方法：

```ts
import { DataScope } from "@/app/generated/prisma/client";
import { PERMISSIONS } from "@/lib/auth/permissions";

import type { PermissionCode } from "@/lib/auth/permissions";
```

然后增加参数校验和保存操作：

```ts
const permissionItemSchema = z.object({
  code: z.string(),
  scope: z.enum(["ALL", "OWN", "ASSIGNED"]),
});

const savePermissionsSchema = z.array(permissionItemSchema);

export async function saveRolePermissionsAction(
  roleId: string,
  values: unknown
): Promise<RoleActionResult> {
  await requirePagePermission("role.assignPermissions");

  const parsed = savePermissionsSchema.safeParse(values);

  if (!parsed.success) {
    return {
      success: false,
      message: "权限配置参数不正确",
    };
  }

  const allowedCodes = Object.entries(PERMISSIONS)
    .filter(
      ([, item]) =>
        item.domain === "BUSINESS" && item.grantable
    )
    .map(([code]) => code);

  const items = parsed.data;

  if (
    new Set(items.map((item) => item.code)).size !== items.length ||
    items.some((item) => !allowedCodes.includes(item.code))
  ) {
    return {
      success: false,
      message: "包含重复或不允许分配的权限",
    };
  }

  for (const item of items) {
    const permission = PERMISSIONS[item.code as PermissionCode];

    if (
      !permission.scopeable &&
      item.scope !== "ALL"
    ) {
      return {
        success: false,
        message: `${permission.name}不支持配置数据范围`,
      };
    }
  }

  const role = await db.role.findUnique({
    where: { id: roleId },
    select: { id: true },
  });

  if (!role) {
    return {
      success: false,
      message: "角色不存在",
    };
  }

  await db.$transaction(async (tx) => {
    await tx.rolePermission.deleteMany({
      where: {
        roleId,
        permissionCode: { in: allowedCodes },
      },
    });

    if (items.length > 0) {
      await tx.rolePermission.createMany({
        data: items.map((item) => ({
          roleId,
          permissionCode: item.code,
          scope: item.scope as DataScope,
        })),
      });
    }
  });

  revalidatePath("/admin/roles");
  revalidatePath(`/admin/roles/${roleId}/permissions`);

  return { success: true };
}
```

这里采用事务完成删除和重新写入，确保不会出现保存到一半的情况。

注意：删除范围限定在当前可分配的业务权限编码中，不会误删其他类型的权限记录。

## 五、实现权限勾选页面

新增：

`app/(dashboard)/admin/roles/[id]/permissions/page.tsx`

```tsx
import { notFound } from "next/navigation";

import { PageHeader } from "@/components/shared/page-header";
import { getRolePermissionConfig } from "@/features/roles/service";
import { RolePermissionForm } from "@/features/roles/components/role-permission-form";

export const instant = false;

export default async function RolePermissionsPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;

  const result = await getRolePermissionConfig(id);

  if (!result) notFound();

  return (
    <div className="space-y-6">
      <PageHeader
        title="分配角色权限"
        description={`正在配置角色：${result.role.name}`}
      />

      <RolePermissionForm
        roleId={id}
        permissions={result.permissions}
        assigned={result.assigned}
      />
    </div>
  );
}
```

## 六、实现复选框交互

新增：

`features/roles/components/role-permission-form.tsx`

这是一个客户端组件，负责维护勾选状态和数据范围。

核心实现如下：

```tsx
"use client";

import { useState, useTransition } from "react";
import { toast } from "sonner";

import { Checkbox } from "@/components/ui/checkbox";
import { Button } from "@/components/ui/button";

import { saveRolePermissionsAction } from "../actions";

type Permission = {
  code: string;
  name: string;
  module: string;
  scopeable: boolean;
};

type Scope = "ALL" | "OWN" | "ASSIGNED";

type Props = {
  roleId: string;
  permissions: Permission[];
  assigned: {
    permissionCode: string;
    scope: Scope;
  }[];
};

export function RolePermissionForm({
  roleId,
  permissions,
  assigned,
}: Props) {
  const [pending, startTransition] = useTransition();

  const [selected, setSelected] = useState<
    Record<string, Scope>
  >(
    Object.fromEntries(
      assigned.map((item) => [
        item.permissionCode,
        item.scope,
      ])
    )
  );

  function toggle(code: string, checked: boolean) {
    setSelected((current) => {
      const next = { ...current };

      if (checked) {
        next[code] = "ALL";
      } else {
        delete next[code];
      }

      return next;
    });
  }

  function changeScope(code: string, scope: Scope) {
    setSelected((current) => ({
      ...current,
      [code]: scope,
    }));
  }

  function save() {
    const values = Object.entries(selected).map(
      ([code, scope]) => ({ code, scope })
    );

    startTransition(async () => {
      try {
        const result = await saveRolePermissionsAction(
          roleId,
          values
        );

        if (result.success) {
          toast.success("角色权限保存成功");
        } else {
          toast.error(result.message ?? "保存失败");
        }
      } catch {
        toast.error("保存失败，请稍后重试");
      }
    });
  }

  const groups = Object.groupBy(
    permissions,
    (item) => item.module
  );

  return (
    <div className="space-y-6">
      {Object.entries(groups).map(([module, items]) => (
        <section
          key={module}
          className="rounded-lg border bg-card p-4 space-y-4"
        >
          <h3 className="font-semibold">{module}</h3>

          <div className="grid gap-4 sm:grid-cols-2">
            {items?.map((item) => {
              const checked = item.code in selected;

              return (
                <div
                  key={item.code}
                  className="flex flex-wrap items-center gap-3"
                >
                  <Checkbox
                    checked={checked}
                    onCheckedChange={(value) =>
                      toggle(item.code, value === true)
                    }
                  />

                  <span className="text-sm">
                    {item.name}
                  </span>

                  {checked && item.scopeable && (
                    <div className="flex gap-1">
                      {(
                        ["ALL", "OWN", "ASSIGNED"] as Scope[]
                      ).map((scope) => (
                        <Button
                          key={scope}
                          size="sm"
                          variant={
                            selected[item.code] === scope
                              ? "default"
                              : "outline"
                          }
                          onClick={() =>
                            changeScope(item.code, scope)
                          }
                        >
                          {{
                            ALL: "全部",
                            OWN: "本人",
                            ASSIGNED: "已分配",
                          }[scope]}
                        </Button>
                      ))}
                    </div>
                  )}
                </div>
              );
            })}
          </div>
        </section>
      ))}

      <div className="flex justify-end">
        <Button onClick={save} disabled={pending}>
          {pending ? "正在保存..." : "保存权限"}
        </Button>
      </div>
    </div>
  );
}
```

这里使用 `Object.groupBy` 按权限目录中的 `module` 分组，让权限配置页面按照业务模块展示，而不是把所有权限混在一起。

## 七、验证功能

完成后重点测试：

1. 在角色列表点击“更多 → 分配权限”，能够进入对应角色的权限配置页面。
2. 页面能够正确回显数据库中已有的授权。
3. 勾选权限后保存，数据库新增对应的 `RolePermission`。
4. 取消勾选后保存，对应授权被删除。
5. 支持数据范围的权限可以切换全部、本人、已分配。
6. 不支持数据范围的权限不能保存为 OWN 或 ASSIGNED。
7. 未授权的用户不能通过直接访问 URL 或调用 Server Action 修改权限。
8. `SYSTEM` 权限不会出现在普通角色的授权列表中。

---

**本篇的核心不是实现几个复选框，而是打通权限目录、角色授权关系和数据范围配置。**

完成之后，角色管理就不再只是管理角色名称和角色成员，而是能够真正决定一个角色可以使用哪些业务功能，以及可以访问哪些数据。
